# Inertia Control Studio / Pendulum Lab: setup

## Current entry point

1. Open `index.html` in a desktop browser for the built demo.
2. For development, follow the original quick-start commands in the README.
3. Read `docs/ENGINEERING_GUIDE.md` for controls and experiment limits.
4. Read `docs/VALIDATION.md` for recorded numerical results.
5. Record the model settings and seed when comparing controllers.

Existing tests were not rerun for this documentation-only change.
